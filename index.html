Tài liệu tham chiếu chuẩn cho kỳ đánh giá môn SWP391 - Nhóm SE2051-NET Group 5

1. Mô hình kiến trúc phân lớp (Layered Architecture)
Trình Duyệt (Web Browser) ──▶ Security Filters (Encoding, Auth, RBAC) ──▶ Controllers (Jakarta Servlets) │ PostgreSQL Database (14 Tables) ◀── Data Access Objects (JDBC DAO) ◀── Service Layer (Business Logic)
Filters: Lọc mã hóa UTF-8, kiểm tra đăng nhập và phân quyền 4 vai trò.
Controllers: Tiếp nhận request HTTP, điều hướng view JSP.
Services: Xử lý nghiệp vụ tính điểm, mã hóa mật khẩu, kiểm tra hợp lệ.
DAOs: Tương tác trực tiếp với PostgreSQL qua JDBC PreparedStatement.

Hướng Dẫn Triển Khai Tomcat 10 & PostgreSQL
  1. Khởi tạo Database: 
    createdb -U postgres courson_db
psql -U postgres -d courson_db -f database/schema.sql
psql -U postgres -d courson_db -f database/seed.sql
  2. Cấu hình `src/main/resources/db.properties`: 
    db.url=jdbc:postgresql://localhost:5432/courson_db
db.user=postgres
db.password=sa
  3. Biên dịch & Đóng gói WAR: 
    mvn clean package -DskipTests
  4. Khởi động Apache Tomcat 10.1+: Copy target/Courson.war vào webapps/ của Tomcat, sau đó truy cập:
    http://localhost:8080/Courson/
